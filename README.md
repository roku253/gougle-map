# Gougle Map

静的 `index.html` + `token-gate.js`。ポータル側のトークンで表示します。画面上はプレイ用 UI と、末尾の**架空サイト注記**のみです（地図ソースや URL パラメータの説明はこの README に記載）。

## ベースマップ

- **スタイル**: OpenFreeMap **Liberty**（OSM ベクトル・MapLibre Style Spec）。タイル URL は `index.html` 内の `BASEMAP_STYLE_URL`。
- **symbol レイヤー**はスクリプトで非表示にし、地形の線・塗りのみ表示します（地名・店アイコンなどはベースマップから消しています）。

物語エリア用のオフライン加工パイプライン（`npm run fetch:osm` など）は別途 `tools/` を参照。派生データを公開する場合は **ODbL（OpenStreetMap）の帰属・ライセンス条件** に従ってください。

## URL パラメータ（開発メモ）

| パラメータ | 用途 |
|-----------|------|
| `embed=kasumi` | 霞ノ杜町公式サイト等への埋め込み。**UI 非表示・町内 POI のみ・範囲制限** |
| `expand=1` | `embed=kasumi` と併用で別タブ向け。**町全体表示・パン／ズーム可**（最小ズームで町外不可） |
| `full=1` | 任務ポータルからプレイ用マップを開くときのフラグ。**これが無い素の URL は自動で `embed=kasumi&expand=1` に戻る** |

トップ `https://…/gougle-map/` だけを開いても、クエリを削っても、**フルマップには入れません**（霞ノ杜限定ビューへリダイレクト）。謎解き本編は `full=1` または `q` / `focus` / `from` など既存の起動パラメータ付きで開いてください。
| `lat`, `lng` | ユーザピンを立て、その地点へズーム（`z` 省略時はコード既定の近接ズーム） |
| `q` | 検索クエリ（店名や `緯度,経度`） |
| `focus` / `f` | `kasumi`, `mikazuki`, `suginami` など |
| `entry` / `from` | `urban-legend-board`（掲示板エントリ）、`sweets-thread` 系（スイーツスレ専用モード）など |

ハッシュ `#kasumi` / `#mikazuki` / `#suginami` も参照されます。

## スイーツタブ

スイーツカテゴリのピンはタブ選択中は低ズームでも表示しますが、**霞ノ杜まち関連**（タイトル・地域・本文・レビュー、`kasumi_local` レビュアーなど）は一覧・レビュー・地図ピンから除外します。

## 座標ピン（ユーザ入力）

検索・「座標」ボタン・`lat`/`lng` URL で置いたピンは、既定で **近いズーム**（`USER_COORD_DEFAULT_ZOOM`）へ `flyTo` し、`moveend` 後にパディングを整えます。

## 公開時の注意（フィクション）

本作は謎解き用の架空サイトです。必要に応じてポータル側でも、フィクションである旨を補足してください。

## POI アイコン

ピンは Google マップ風の形＋**色付き円**＋**白シルエットアイコン**で表示します。

- 定義: `data/poi-icons.json`（24 種＋ **`dot`（●）その他**）
- 画像: `img/icons/`（PNG/SVG を涙型ピンの円内に表示。円の色は `iconColor` で変更）
- 各ピン: `iconId`（アイコン種別）と `iconColor`（円の色・任意）を `map-data.json` に保存
- 編集パネル「ピン」タブでアイコン・色を変更可能

## ローカル開発・地図データ編集

ピン・地域ラベルは `data/map-data.json` に集約しています。本番（GitHub Pages 等）でもこの JSON を読み込みます。

### サーバー起動

```bash
npm run dev
```

- 既定ポートは **5199**（3000 番台など他プロジェクトと競合しにくい番号）
- 5199 が使用中なら **5200〜5208** を自動で試します
- 別ポートにしたいとき: `GOUGLE_MAP_DEV_PORT=5210 npm run dev`（PowerShell では `$env:GOUGLE_MAP_DEV_PORT=5210; npm run dev`）

起動ログに表示される URL（例: `http://127.0.0.1:5199/?full=1`）をブラウザで開いてください。`?full=1` が無いと霞ノ杜ビューへ戻るので、編集時は必ず付けた URL を使います。

### 編集手順

1. `npm run dev` でサーバーを起動する
2. 表示された `http://127.0.0.1:5199/?full=1` を開く（localhost なのでトークン不要）
3. 検索バー左の **Gougle ロゴを10回連続クリック** → 右上に「地図編集」パネルが開く
4. **ピンタブ**
   - 地図の空き場所をクリック → 新規ピン追加
   - ピンをドラッグ → 位置変更
   - ピンをクリック、またはプルダウンで選択 → タイトル・エリア・カテゴリ・アイコン・座標・本文を編集 →「選択ピンに反映」
   - 不要なピンは「削除」
   - **表示開始ズーム**を個別設定（空欄＝全体既定）
5. **ラベルタブ**（町名・川名などの文字ラベル）
   - ラベルを**クリック** → 選択（青い枠）
   - ラベルを**ドラッグ** → 位置移動
   - 地図をクリック → 川名などの**追加ラベル**を新規配置（ラベルタブ選択時）
   - 名前・サブタイトル・座標・**表示開始ズーム**・**角度（°）**・**文字サイズ／太字／色／ふち**を編集 →「ラベルに反映」
   - 「見た目を既定に戻す」でスタイルだけリセット
   - 三日月町／杉並ヶ岡／霞ノ杜町の町名ラベルも同様に移動・編集可
   - 川名など追加ラベルは「追加ラベルを削除」で除去
6. パネル下部の **全体の表示既定** で、ピン／町名／追加ラベルのデフォルトズームを変更
7. **「JSONに保存」** → `data/map-data.json` に書き込み（この dev サーバー経由のみ可能）
8. 本番へ反映するときは `data/map-data.json` をコミットしてデプロイ

`file://` で `index.html` を直接開くと JSON の読み込みや保存 API が動きません。必ず `npm run dev` 経由で編集してください。

## 設定

`token-gate.js` の `TOKEN_GATE_ORIGIN` を本番ポータルに合わせてください。
